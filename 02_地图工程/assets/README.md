# 北化昌平校区 · 等距像素资产库（v3.8）

北京化工大学昌平校区 2.5D 等距（isometric）数字校园的**像素风建筑资产库**，共 16 个点位。
统一规格：等距体素像素风、左上光照、红墙灰顶蓝玻璃配色，32 色、逻辑 400px 宽、NEAREST 放大 4 倍输出（1600px）。

## 目录结构（按用途 + 功能分类，便于 git 与引擎接入）

```
assets/
├── manifest.json              # 资产清单（ID/名称/分类/文件/逻辑尺寸/网格坐标/层数），程序读取唯一入口
├── README.md
├── sprites/                   # 【引擎调用版】透明底 RGBA，Tiled / Cocos Creator 直接按网格放置
│   ├── teaching/              #   教学科研：TEACH-1 一教、TEACH-2 二教、LAB-TECH 实验楼、WENLI 文理、ENG-TRAIN 泰瑞楼
│   ├── public/                #   公共服务：LIB 图书馆、ACT 大学生活动中心
│   ├── sports/                #   体育：FIELD-W 西田径场、FIELD-N 北操场、GYM 体育馆
│   ├── dining/                #   餐饮：CAN-YULAN 玉兰食堂、CAN-ZIZHU 紫竹食堂
│   ├── gate/                  #   校门：GATE-S 南门（主校门）、GATE-E 东门、GATE-W 西门
│   └── nature/                #   自然地标：MOUNT-YUPING 玉屏山
├── preview/                   # 【展示版】浅绿草地底座、RGB 不透明；子目录分类与 sprites 一致，用于图鉴/宣传/PPT
│   └── <group>/<ID>.png
├── source/                    # 【高清源】2048 等距体素、未做 32 色量化；用于重新像素化/放大/再加工，引擎无需打包
│   └── <group>/<ID>.png
└── catalog/                   # 【图册】
    ├── 总体排布资产图.png      # 16 栋按真实等距坐标贴回 + 真实路网的校园总览（9130×4705）
    └── 资产图鉴_16点位.png     # 16 栋带编号+名称的单栋图鉴
```

> 三层分工：`sprites/` 引擎运行时调用（透明底，最小依赖）；`preview/` 仅供展示与文档，引擎无需打包；`source/` 为 2048 高清源，供再加工。
> 单张透明资产为正方形 1600×1600；横向建筑（一教 TEACH-1、玉屏山 MOUNT-YUPING）为 1600×1068。

## 等距坐标约定（与 render_iso / Tiled / Cocos 一致）

- 地块尺寸：`TW=44, TH=22`（等距菱形 2:1）；层高 `FLOOR_H=14`。
- 网格 → 屏幕：`iso(gx,gy) = ((gx−gy)*22, (gx+gy)*11)`。
- 屏幕方向：东（gx+）→ 屏幕右下，南（gy+）→ 屏幕左下；朝相机的是东墙与南墙。
- 每个资产的屏幕地块菱形：水平宽 `(gw+gh)*22`，垂直高 `(gw+gh)*11`，地块中心为 `iso(gx+gw/2, gy+gh/2)`。
- 总图贴回脚本：`build/compose.py`（读取 manifest，按 `gx+gy` 深度排序后 alpha_composite）。

## 道路层（真实路网提取）

- 道路严格按官方平面图 `01_资料与参考/official_map.jpg`（北校区工作办公室 2021.8 制）真实存在的马路提取，脚本：`build/roads_extract.py`。
- 提取流程：白色判据 `(R>180,G>170,B>165)` → 大核腐蚀分离面状空地/停车场 → 校园轮廓多边形裁切 → **窄通道重建**（距离变换恢复跨河窄桥，避免铺装龟裂纹）→ 高斯平滑（先 dilate1 护住窄桥）。
- 结果：主路网连通度约 95%，16 栋建筑全部接入主路网；含跨河桥、南门转盘、东/西环路、运动场通道。
- 渲染：`roads_extract.ground_layer(K=8)` 生成正交地面道路层，由 `render_iso.py` 一次 `warpAffine` 仿射贴到等距地面；路面 `(208,204,192)`、路肩 `(150,148,138)`。

## 在 Tiled / Cocos Creator 中调用

1. 地面（草地/道路/水系/山体/公园绿地）作为独立底图层，由 `build/render_iso.py` 生成；道路使用 `build/roads_extract.py` 的真实路网。
2. 建筑 sprite 使用 `sprites/<group>/<ID>.png`（透明底），按 `manifest.json` 中 `grid` 放置：
   - 屏幕锚点 = 地块中心 `iso(gx+gw/2, gy+gh/2)`；
   - 缩放比 = 目标地块宽 `(gw+gh)*22` ÷ 贴图水平占地宽（见 `build/compose.py`）；
   - 按 `gx+gy` 从小到大排序绘制（远→近）。
3. 逻辑像素 400、32 色为统一基准；需要更高清可使用 `source/<group>/<ID>.png`（2048 等距体素，未做颜色量化）。
4. 田径场/玉屏山的草坪与山体属于场地本体，透明底已保留；楼体仅保留楼体+投影。
