# 北化昌平校区 · 等距像素数字校园（网页端）

北京化工大学昌平校区 2.5D 等距（isometric）像素数字校园的**可交互网页端**：
等距真实路网底图 + 16 栋像素建筑，支持地图浏览、缩放、建筑点位信息卡（含配图）、chibi 角色行走、自动寻路、建筑名标签与小地图导航。

## 一、启动方式（开箱即用，推荐）

内置**零依赖**本地服务器（Python / Node 任一即可，无需 pip / npm 安装任何东西），启动后自动打开浏览器，并支持**同一局域网的手机/平板访问**。

| 系统 | 操作 |
|---|---|
| Windows | 双击 **`启动网页端.bat`** |
| macOS | 双击 **`启动网页端.command`**（首次被 Gatekeeper 拦截时，右键 → 打开） |
| Linux | 终端执行 **`./启动网页端.sh`** |

启动后会显示（浏览器自动打开）：

```
本机访问：    http://127.0.0.1:8080/
局域网/手机： http://192.168.x.x:8080/   # 手机连同一 WiFi 即可访问
停止服务：    关闭窗口，或按 Ctrl+C
```

> 8080 被占用会自动顺延端口；也可手动指定：`python3 server.py 9000` 或 `node server.js 9000`。
> 手动命令二选一：`python3 server.py`（优先）或 `node server.js`（兜底）。

## 二、直接打开（无服务器，最简单）

也可**直接双击 `index.html`** 离线运行（无需安装、无需联网）。区别：无服务器时不能给手机/局域网访问，个别浏览器对 `file://` 限制较严时改用上面的方式。

## 三、操作

| 操作 | 功能 |
|---|---|
| `W / A / S / D` 或方向键 | 控制角色移动（移动后相机自动跟随） |
| 鼠标拖拽 / 单指拖动 | 平移地图 |
| 滚轮 / 双指捏合（手机） | 缩放，双指以两指中点为中心 |
| 右下角虚拟摇杆（手机） | 无键盘时控制角色 4 方向行走 |
| 点击建筑 | 弹出点位信息卡（编号/名称/分类/介绍 + 像素配图） |
| 信息卡「前往这里」 | 沿道路自动寻路走到该建筑 |
| 点击空地 | 自动寻路走到该点 |
| 左下角小地图 | 实时位置/视野框/路线，点击直接飞行定位 |
| 放大地图 | 建筑顶部显示名称 |
| 「跟随角色 / 重置视角」按钮 | 回到跟随角色 / 整校园全貌 |

角色初始位于南门；遇到教学楼、实验楼、体育馆、食堂、校门等实体建筑会被挡住（可贴墙滑动），操场、山体等开敞场地可进入。

**手机 / 平板**：单指拖动平移、点建筑弹卡、点空地寻路，双指捏合缩放，右下角虚拟摇杆控制角色；界面自动按竖屏 / 横屏重排，已禁用浏览器默认缩放手势，桌面端则显示完整键盘操作说明。

## 四、目录结构

```
03_地图预览器/
├── index.html            # 入口（HUD、信息卡、小地图、加载层）
├── server.py             # 零依赖本地服务器（Python 3，优先）
├── server.js             # 零依赖本地服务器（Node.js，兜底）
├── 启动网页端.bat         # Windows 一键启动
├── 启动网页端.command     # macOS 一键启动
├── 启动网页端.sh          # Linux 一键启动
├── js/
│   ├── data.js           # 自动生成：地面/投影常量/16 建筑放置参数与信息（勿手改）
│   └── main.js           # 渲染、相机、输入、角色、碰撞、寻路、标签、小地图
└── img/
    ├── ground.png        # 等距地面底图（草地+真实路网+水系+山体，菱形外透明，9130×4705）
    ├── sprites/          # 16 栋透明底建筑（与 02_地图工程/assets/sprites 同源）
    └── player/           # chibi 角色 4 方向×4 帧走路序列帧
```

## 五、数据与坐标（与地图工程严格一致）

- 等距投影：屏幕坐标 `((gx−gy)*22 + ox, (gx+gy)*11 + oy)`。
- 地面底图与建筑放置参数由 `02_地图工程/build/export_web_assets.py` 从权威数据
  `campus_data.py / manifest.json / map_data.json` 导出，与总体排布图逐像素对齐。
- 道路为官方平面图真实马路（`build/roads_extract.py`，主路网连通度 94.6%）。
- 自动寻路采用旋转坐标 BFS（`u=gx+gy, v=gx−gy`）沿道路搜索，避开建筑实体。
- **重新生成**：修改建筑/道路后，在 `02_地图工程/build/` 执行 `python3 export_web_assets.py`，
  会自动刷新 `img/ground.png`、`img/sprites/` 与 `js/data.js`。

## 六、与 Cocos 的关系

本网页端是 Cocos Creator 3.8 工程的交互验证与同源前端：`data.js` 与 Cocos 的
`CampusData.ts` 由同一份权威数据生成，`sprites/`、`player/` 资源两端一致，逻辑
（投影/碰撞/寻路）可一一对应，见 `04_Cocos工程/`。
