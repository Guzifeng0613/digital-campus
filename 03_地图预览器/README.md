# 北化昌平校区 · 等距像素数字校园（浏览器预览器）

北京化工大学昌平校区 2.5D 等距（isometric）像素数字校园的**可交互网页预览**：
等距真实路网底图 + 16 栋像素建筑，支持地图浏览、缩放、建筑点位查看，以及角色在校园里行走（带建筑碰撞与前后遮挡）。

## 打开方式（零依赖，纯静态）

**直接双击 `index.html`** 即可在浏览器中运行（无需安装任何东西、无需联网、无需服务器）。

> 若个别浏览器对本地 `file://` 限制较严，可在本目录起一个静态服务器：
> ```
> python3 -m http.server 8765
> ```
> 然后浏览器访问 `http://localhost:8765/`。

## 操作

| 操作 | 功能 |
|---|---|
| `W / A / S / D` 或方向键 | 控制角色移动（屏幕方向，移动后相机自动跟随） |
| 鼠标拖拽（或单指拖动） | 平移地图 |
| 鼠标滚轮 | 以鼠标为中心缩放 |
| 点击建筑 | 查看该点位的编号、名称、分类与介绍 |
| 「跟随角色」按钮 | 相机回到跟随角色 |
| 「重置视角」按钮 | 回到整校园全貌（居中） |

角色初始位于南门，可沿道路/校园开敞区域行走；遇到教学楼、实验楼、体育馆、食堂、校门等实体建筑会被挡住（可贴墙滑动），操场、山体等开敞场地可进入。

## 目录结构

```
03_地图预览器/
├── index.html          # 入口（HUD、信息卡、加载层）
├── js/
│   ├── data.js         # 自动生成：地面/投影常量/16 建筑放置参数与信息（勿手改）
│   └── main.js         # 渲染、相机、输入、角色行走与碰撞、深度排序、点位拾取
└── img/
    ├── ground.png      # 等距地面底图（草地+真实路网+水系+山体，菱形外透明，9130×4705）
    └── sprites/        # 16 栋透明底建筑（与 02_地图工程/assets/sprites 同源）
```

## 数据与坐标（与地图工程严格一致）

- 等距投影：地块 `TW=44, TH=22`（2:1），屏幕坐标 `((gx−gy)*22 + ox, (gx+gy)*11 + oy)`。
- 地面底图与建筑放置参数由 `02_地图工程/build/export_web_assets.py` 从权威数据
  `campus_data.py / manifest.json / map_data.json` 导出，与
  `assets/catalog/总体排布资产图.png` 逐像素对齐（贴回一致性 >91%，差异仅为编号徽章）。
- 道路为官方平面图真实马路（`build/roads_extract.py`，窄通道重建，主路网连通度 94.6%）。
- **重新生成**：修改建筑/道路后，在 `02_地图工程/build/` 执行 `python3 export_web_assets.py`，
  会自动刷新 `img/ground.png`、`img/sprites/` 与 `js/data.js`。

## 渲染要点

- 地面菱形外透明，页面背景为深色径向渐变；建筑按 `gx+gy` 深度排序，角色与建筑共同排序，
  实现正确的「近遮远、楼遮人 / 人遮楼」。
- 建筑点选用**等距逆变换到网格→判定地块菱形**，重叠区域也能精确拾取，不依赖像素抠图。
- 建筑缩放低于 0.85 时开平滑抗锯齿（避免缩放摩尔纹），放大后切像素硬边保持像素风。

## 后续对接

- 本预览器是 Cocos Creator 3.8 接入前的交互验证：`data.js` 的网格坐标/碰撞盒/深度可直接平移为
  Cocos 的 Tile 坐标、节点 position 与 z-order；`sprites/` 可直接作为 SpriteFrame。
- 角色目前为代码绘制的像素小人，可在 Cocos 工程中替换为正式角色骨骼/序列帧。
