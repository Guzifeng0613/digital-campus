# 北化昌平校区 · 星露谷式像素数字校园（网页端）

北京化工大学昌平校区 **星露谷式 2:1 等距 3/4 高角度斜俯视（立体）像素数字校园** 的可交互网页端：
按官方平面图真实路网绘制的地块 + 16 点位写实材质像素立体建筑（含完整屋顶、朝南高墙立面、侧墙与落地投影），
支持地图浏览、建筑点位信息卡（含配图）、chibi 角色行走 / 跑步、自动寻路、**操场围栏唯一入口门开合动画**、
建筑名标签、进入场地横幅与小地图导航，并做了手机 / 平板竖屏适配。

## 一、启动方式（开箱即用，推荐）

内置**零依赖**本地服务器（Python / Node 任一即可，无需 pip / npm 安装任何东西），启动后自动打开浏览器，
并支持**同一局域网的手机 / 平板访问**（这就是「后端启动 → 前端直接访问」的方式：本机跑一个静态服务，手机连同一 WiFi 打开打印的地址即可）。

| 系统 | 操作 |
|---|---|
| Windows | 双击 **`启动网页端.bat`** |
| macOS | 双击 **`启动网页端.command`**（首次被 Gatekeeper 拦截时，右键 → 打开） |
| Linux | 终端执行 **`./启动网页端.sh`** |

启动后会显示（浏览器自动打开）：

```
本机访问：    http://127.0.0.1:8090/
局域网/手机： http://192.168.x.x:8090/   # 手机连同一 WiFi 即可访问
停止服务：    关闭窗口，或按 Ctrl+C
```

> 端口被占用会自动顺延；也可手动指定：`python3 server.py 9000` 或 `node server.js 9000`。
> 手动命令二选一：`python3 server.py`（优先）或 `node server.js`（兜底）。

## 二、直接打开（无服务器）

也可**直接双击 `index.html`** 离线运行（无需安装、无需联网）。区别：无服务器时不能给手机 / 局域网访问，
个别浏览器对 `file://` 限制较严时改用上面的方式。

## 三、操作

| 操作 | 功能 |
|---|---|
| `W / A / S / D` 或方向键 | 控制角色移动（移动后相机自动跟随） |
| `Shift`（按住） | 跑步（移速更快、切换跑步帧） |
| 鼠标拖拽 / 单指拖动 | 平移地图 |
| 滚轮 / 双指捏合（手机） | 缩放，以鼠标 / 双指中点为中心 |
| 右下角虚拟摇杆（手机） | 无键盘时控制角色行走 |
| 点击建筑 | 弹出点位信息卡（编号 / 名称 / 分类 / 介绍 + 立体像素配图） |
| 信息卡「前往这里」 | 自动寻路走到该建筑（操场会走到唯一门内） |
| 点击空地 | 自动寻路走到该点 |
| 左下角小地图 | 实时位置 / 视野框 / 寻路路线，点击直接飞行定位 |
| 放大地图 | 建筑顶部显示名称标签 |
| 「跟随角色 / 重置视角」 | 回到跟随角色 / 整校园全貌 |

**场地围栏**：风雨操场（蓝跑道、中间纯草地）、北操场（红跑道、足球场）四周有围栏，**只能从唯一的门进入**；
角色走近门时像素门自动打开放行，进入瞬间显示「进入 · 场地名」横幅，离开后自动闭合。教学楼、实验楼、体育馆、
食堂、校门等实体建筑会被挡住（可贴墙滑动），操场、山体等开敞场地可进入。

**手机 / 平板**：单指拖动平移、点建筑弹卡、点空地寻路，双指捏合缩放，右下角虚拟摇杆控制角色；
界面自动按竖屏 / 横屏重排（标题、按钮、信息卡自适应），已禁用浏览器默认缩放手势。

## 四、目录结构

```
03_地图预览器/
├── index.html            # 入口（HUD、信息卡、小地图、加载层、移动端适配）
├── server.py             # 零依赖本地服务器（Python 3，优先）
├── server.js             # 零依赖本地服务器（Node.js，兜底）
├── 启动网页端.bat/.command/.sh   # 三平台一键启动
├── js/
│   ├── data.js           # 16 点位元数据：grid 地块、分类、介绍、配图
│   ├── topdown_data.js   # 自动生成：道路 / 水系 / 自然地块的网格折线（勿手改）
│   └── main.js           # 等距投影、地块 / 道路 / 围栏渲染、相机、输入、
│                         #   chibi 角色（idle/走/跑）、碰撞、BFS 寻路、
│                         #   门动画、进入横幅、建筑名标签、小地图
└── img/topdown/
    ├── sprites/          # 16 栋透明底 3/4 立体像素资产
    ├── tiles/            # 草地 / 土路 / 硬铺 / 水面 / 路口等地面 tile
    ├── decor/            # 围栏（横/竖/角/门）、树、灌木、灯杆、旗杆、花坛、长椅等装饰
    └── player/           # chibi 角色：4 方向 × (idle + 走 4 帧 + 跑 4 帧)，共 36 帧
```

## 五、数据与坐标

- 逻辑网格 `gx,gy`（gx=东向、gy=南向）与投影解耦；等距投影 `TW=64 / TH=32`：
  屏幕世界坐标 `isoX=(gx−gy)*32`、`isoY=(gx+gy)*16`（标准 2:1 等距）。
- 每栋建筑用 `grid=[fx,fy,fw,fh]`（地块矩形）+ 锚点 `ANCHOR_AX/AY` 与缩放 `ISO_K`
  把立体 sprite 的南角对齐到地块菱形，按深度排序，形成前后遮挡。
- 道路为官方平面图真实马路（`topdown_data.js`），土路 / 硬铺 / 路口按 tile 与矢量折线绘制，
  水系、山体、地块按真实位置排布。
- 自动寻路采用旋转坐标 BFS（`u=gx+gy、v=gx−gy`），沿可行走区域搜索、避开实体建筑与围栏（唯一门缺口放行），
  对角移动不穿墙角；目标点被挡时自动取最近可达点。

## 六、与 Cocos Creator 工程的关系

`04_Cocos工程/` 是同一套数据与资源的 Cocos Creator 3.8 接入版本（运行时脚本自动生成等距地图、
相机、角色与交互，无需手工拖节点）。本网页端用于快速交互验证与直接部署，二者数据 / 资源同源。

> 说明：当前网页端为最新的星露谷式 3/4 立体（topdown）版本；如在 Cocos 端预览，需以本目录
> `img/topdown/` 与 `js/` 为准同步资源与等距逻辑。
