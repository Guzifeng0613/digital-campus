# 北化数字校园 · 像素插图提示词手册

> 适用范围：北京化工大学昌平校区 16 栋核心建筑 + 角色的等距像素风资产生成、复现与扩展。
> 版本：v1.0 ｜ 对应资产库：`02_地图工程/assets/`（sprites/preview/source 三层）

---

## 一、通用风格规范

| 维度 | 规范 |
|---|---|
| 视角 | 等距（isometric），约 30° 俯视，建筑正面偏右可见 |
| 风格 | 像素艺术（pixel art），16-bit 色板感，硬边无抗锯齿 |
| 配色 | 校园暖色调；建筑主色尽量贴近实物（红砖/灰墙/蓝顶等），允许润色修色 |
| 光照 | 统一左上光源，右侧/底部投柔和短阴影；不做强烈高光 |
| 背景 | 生成时用纯白或纯绿底，后期抠图为透明 PNG；禁止带场景/天空/地面 |
| 构图 | 建筑居中，占画面 70–85%，底部留少量投影空间；不画人物/车辆/文字 |
| 分辨率 | 源图 2048×2048；像素化后逻辑 400×400（操场/山体等可 400×600），放大 4 倍输出 1600px |

## 二、标准生成流程

```
真实照片/官方平面（轮廓依据）
        │
        ▼
① seedream 5.0 Pro 生成高清等距图（2048px，参考图锚定轮廓）
        │
        ▼
② pixelate 像素化：quantize 32 色 + nearest 缩放至 logical_size
        │
        ▼
③ 抠图去背景 → 透明底 RGBA
        │
        ▼
④ 按等距网格坐标贴回总体排布图（compose.py）
        │
        ▼
⑤ 归档：sprites/<group>/（透明底）、preview/<group>/（浅绿底座展示）、source/<group>/（高清源）
```

- 关键原则：**轮廓以真实照片/官方平面为准，颜色和细节可润色**；用户明确"不需要完全和实物一模一样"。
- 像素化后必须检查：边缘是否干净、透明通道是否完整、放大后是否有杂色。

## 四、角色像素帧生成

角色不使用 AI 生图，采用**程序化编码生成**，保证帧精确、风格统一、可复现：

- 脚本：`02_地图工程/build/gen_player_frames.py`
- 输出：`04_Cocos工程/assets/resources/player/player_<direction>_<frame>.png`
- 规格：4 方向（down/up/left/right）× 4 走路帧 = 16 张，64×64 RGBA 透明底
- 配色：红上衣 `(217,79,58)`、深蓝裤 `(43,52,80)`、黑发 `(58,42,28)`、肤色 `(242,199,155)`
- 走路循环：frame0 站立 → frame1 左腿前 → frame2 站立 → frame3 右腿前
- 接入：Cocos `CampusBootstrap.loadPlayerFrames()` 加载，`updatePlayerFrame()` 按 `facing + phase` 切帧；放大走 `Texture2D.Filter.POINT` 保持像素硬边；加载失败自动回退 Graphics 代码绘制。

## 五、资产命名与目录规范

```
02_地图工程/assets/
├── sprites/<group>/<ID>.png      # 透明底，Tiled/Cocos 调用（1600px RGBA）
├── preview/<group>/<ID>.png      # 浅绿底座展示版
├── source/<group>/<ID>.png       # 2048 高清未量化源（再加工用）
├── catalog/                       # 总体排布图、单栋对照、角色精灵图
└── manifest.json                  # 16 栋完整元数据（id/name/category/grid/尺寸）
```

- 分组：`teaching`（一教/二教/实验/文理/泰瑞）、`public`（图书馆/活动中心）、`sports`（风雨操场/北操场/体育馆）、`dining`（玉兰/紫竹）、`gate`（南/东/西）、`nature`（玉屏山）。
- ID 大写英文，文件名与 `manifest.json` 一致，禁止中文文件名。
- 新增建筑时：在 `manifest.json` 登记 → 生成三层资产 → 更新 `campus_data.py` 网格坐标 → 重跑 `gen_map_data.py` / `export_web_assets.py` / `gen_cocos.py`。

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 生成的建筑轮廓与实物差太大 | 用 `image_edit` 以真实照片为锚点参考，提示词强调布局特征（如"双D形翼+连廊"） |
| 像素化后边缘有杂色/光晕 | 重新 quantize 或先抠图再像素化；检查透明通道 |
| 等距视角不一致 | 提示词统一加"等距视角，约30度俯视"；生成后对比已有资产的地平线角度 |
| 颜色太艳/太灰 | 提示词加"柔和配色，校园暖色调"；后处理可微调饱和度 |
| 角色帧想换风格 | 修改 `gen_player_frames.py` 中的颜色常量和像素布局，重跑即可 |
