# PR：等距 2.5D 像素风北化昌平校区数字校园地图（Web 预览器 + Cocos Creator 3.8）

> 合并分支：`feat/iso-campus-map` → `main`
> 建议 PR 标题（可直接复制）：
> **feat: 等距 2.5D 像素风北化昌平校区数字校园地图（Web 预览 + Cocos Creator 3.8）**

---

## 一、概述

为**北京化工大学昌平校区**制作的等距（Isometric）2.5D 像素风数字校园地图：基于官方平面图还原真实路网与 16 个核心点位的像素建筑，提供一个可自由行走的 chibi 角色，并实现地图浏览、点位信息卡、自动寻路、建筑名标签、小地图导航等完整交互。

交付两份可运行产物：

- **零依赖网页预览器**：纯静态 HTML/JS，双击 `index.html` 即可离线运行，无需服务器。
- **Cocos Creator 3.8 工程**：一个引导脚本 `CampusBootstrap` 在运行时自动生成 Canvas、正交相机、地图、角色、HUD 与全部交互，无需在编辑器里逐个拖节点。

---

## 二、主要功能

| 功能 | 说明 |
|---|---|
| 地图浏览 | 鼠标/触屏拖拽平移、滚轮缩放（以鼠标为中心）、一键全貌居中、跟随角色 |
| 16 点位信息卡 | 点击建筑弹出编号/名称/分类/简介，**顶部展示该建筑像素模型配图**，含「前往这里」按钮 |
| chibi 角色 | 大头小身像素女孩，4 方向 × 4 帧走路动画，带影子；WASD/方向键行走 |
| 碰撞与遮挡 | 轴分离移动 + 建筑实体碰撞（可贴墙），操场/玉屏山可进入；精灵按深度自动排序 |
| 自动寻路 | 点击空地或「前往这里」，沿道路自动寻路；实时虚线、终点标记、到达提示、卡住自检、手动取消 |
| 建筑名标签 | 放大到阈值后在建筑顶部显示名称，随视野裁剪 |
| 小地图导航 | 左下角全校缩略图：分类色点、角色脉冲点、当前视野框、寻路路线；点击小地图飞行定位（仅响应菱形校园内） |

## 四、技术要点

- **等距投影**：网格 `(gx,gy)` → 世界/图像坐标 `(gx-gy)*SX, (gx+gy)*SY`；建筑按 `gx+gy` 深度排序，角色在建筑间正确遮挡。
- **自动寻路**：道路沿屏幕水平/垂直方向（等距网格的对角），采用**旋转坐标 BFS**（`u=gx+gy, v=gx-gy`），8 方向搜索、对角避墙角，解决了普通网格 BFS 贴墙道路被误判不可走的问题。
- **移动**：整体移动 + 轴分离贴墙；沿路径点连续行走，带卡住检测（停滞则跳过死点），手动按键立即取消。
- **像素资产流水线**：真实照片校准轮廓 → 2.5D 等距建模渲染 → AI 像素化（限定色板）→ 透明底抠图 → 规范命名/目录归档；角色为 4×4 精灵图自动抠绿、切帧、对齐。
- **Cocos 运行时生成**：资源走 `resources.load` 不依赖 `.meta` UUID；空场景只需挂一个脚本即可看到完整地图。
- **数据同源**：权威数据模型 `02_地图工程/build/campus_data.py` 导出网页 `data.js` 与 Cocos `CampusData.ts`，两端 16 点位、坐标完全一致。

## 六、快速开始

### 网页预览器
双击 `03_地图预览器/index.html`（或任意静态服务器打开）即可离线运行。

### Cocos Creator 3.8
1. Cocos Dashboard → 添加 → 选择 `04_Cocos工程/`，用 3.8.x 打开。
2. 新建/打开一个场景，创建空节点命名 `Campus`，把 `assets/scripts/CampusBootstrap.ts` 拖到该节点上。
3. 保存场景，点击 ▶ 预览（脚本会自动创建 Canvas/相机/地图/角色/交互）。
- 详见 `04_Cocos工程/README.md`（含拷进空工程的兜底方法）。

## 八、已知限制与后续

- Cocos 端的**引擎真机运行**未在本机验证（无编辑器 GUI），需在 Cocos Creator 里 ▶ 预览确认；如遇报错，按 F12 控制台信息反馈。
